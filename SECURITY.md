# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

Please report security vulnerabilities privately to **eventheoddsfoundry@gmail.com**.

Include:
- Description of the issue
- Steps to reproduce
- Potential impact
- Any suggested mitigations

We aim to acknowledge reports within 72 hours and provide a remediation timeline within 14 days for high-severity issues.

## Scope

This research track currently provides classical cryptographic commitments over process-matrix descriptions. Quantum-side channels or side-channel attacks on any future hardware implementation are out of scope until an experimental release is tagged.

Thank you for helping keep Even The Odds Foundry systems secure.
